# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn using SQL, SAS, and Power BI to identify the factors that influence customer attrition and provide business insights for improving customer retention.

The project demonstrates the complete analytics workflow including data exploration, business analysis, statistical analysis, and dashboard development.

## 💡 Key Insights

- Customers with Month-to-Month contracts show significantly higher churn.
- Fiber Optic users exhibit higher churn than DSL customers.
- Customers with shorter tenure are more likely to churn.
- Monthly charges are generally higher for customers who churn.
- Contract type has a strong influence on customer retention.
